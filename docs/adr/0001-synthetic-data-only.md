# 0001. Synthetic personal data only, with checksum-valid identifiers

- Status: Accepted
- Date: 2026-11-21

## Context

KVKK (Law No. 6698) treats national ID numbers, IBANs, contact details and similar fields as personal
data. A public portfolio repository must never contain data about real people, yet detectors and
masks are only meaningful if they are tested on realistic formats.

## Decision

- All people are generated by `sdai/synth.py` from a fixed seed: random combinations of common first
  names and surnames, random cities and dates.
- TCKN and TR IBAN numbers are random digits **with valid checksums**; they are not issued to anyone.
  Card numbers use the 9-prefix, which no card network issues. E-mails use the reserved `example.com`
  domain. Phone numbers are random +90 5xx numbers.
- Generated datasets live in memory or under the git-ignored `data/` directory. Only small samples,
  needed to show what a role sees, appear in `results/`.

## Consequences

- Recall of 1.0 in the PII evaluation reflects template-generated notes; real free text is messier
  (see README limitations).
- A random 11-digit number passes the TCKN checksum about 1 time in 100, and a random 16-digit number
  passes Luhn 1 time in 10. Those collisions are what the precision numbers measure.
